# SMM timescale compare (월 일자료 1개 · 격자 1개)

방법 정의, 용어, 한 달 자료의 한계는 [references/research.md](references/research.md)에 있습니다. 계산 전에 읽으세요.

## 입력 범위

- **nc 파일 1개:** 한 달치 연속 일자료. `time`이 두 달 이상에 걸치거나 하루씩 이어지지 않으면 스크립트가 오류로 멈춥니다.
- **격자 1개:** 위도·경도 하나. 스크립트가 그 지점에서 가장 가까운 육지 격자를 고릅니다.
- 이 범위를 벗어나는 요청이면 스크립트를 고치지 말고 사용자에게 먼저 확인하세요.

## 지켜야 할 것

1. **원본 nc 파일은 절대 수정하지 않습니다.** 읽기 전용으로만 엽니다. 스크립트는 `netCDF4.Dataset(path, 'r')`만 씁니다.
2. **결과는 저장소 최상위 `results/`에만 저장합니다.** 스킬 폴더 안에는 저장하지 않습니다. 스크립트 기본값이 이미 `<repo>/results`이므로 `--outdir`은 지정하지 않습니다.
3. **적용할 수 없거나 신뢰도가 낮은 방법도 빼지 않습니다.** 표에 "계산 불가", "적용 불가", "계산 안 함"으로 남기고 이유를 적습니다.
4. **사용한 격자의 실제 위경도, 요청 지점과의 거리, 변수 단위를 보고합니다.**
5. **전처리 내용은 비교표 바로 위에 적습니다.** 어떤 전처리를 했는지(평균 제거, 선형 추세 제거), 무엇을 하지 않았는지(deseasonalization), 어떤 방법이 원자료를 쓰는지(drydown)를 적습니다.
6. **보고하는 숫자는 스크립트 출력이나 결과 파일에서 그대로 가져옵니다.** 평균 같은 값을 직접 암산하지 않습니다. 예전에 30일 평균을 손으로 계산했다가 틀린 적이 있습니다.
7. 정의를 원문으로 확인하지 못한 방법(현재 McColl et al., 2019 hybrid)은 추측으로 공식을 만들지 않고 "계산 안 함"으로 둡니다.

## 작업 순서

1. **입력 확인.** 파일 경로와 위경도를 확인하고 헤더를 봅니다.
   ```bash
   ncdump -h <file.nc> | head -80
   ```
   확인할 것: 토양수분 변수(`swvl1` 등)와 단위, 강수 변수(`mtpr`), `lsm` 유무, `sst` 유무, 격자 간격, `time` 길이와 단위.
   격자 간격이나 변수 구성이 자료 이름과 맞지 않으면(예: "ERA5-Land"인데 0.25° 격자) 보고에 적습니다.

2. **계산 실행.** 저장소 최상위에서 실행합니다.
   ```bash
   python .claude/skills/smm-timescale-compare/scripts/compute_tsmm.py <file.nc> --lat <위도> --lon <경도>
   ```
   - `--var`: 토양수분 변수 (기본 `swvl1`)
   - `--pvar`: 강수율 변수, kg m⁻² s⁻¹ (기본 `mtpr`). 없으면 drydown 구간을 고를 때 강수 조건 없이 감소 구간만 씁니다.
   - 육지 판정: `sst`가 NaN이고 토양수분이 유효하며 0보다 큰 격자 중 대권거리가 가장 가까운 격자(±1° 안).

3. **결과 파일 확인.** `results/`에 아래 세 파일이 생깁니다. 이름의 `<tag>`는 `<var>_<YYYYMM>_<lat>N_<lon>E`이고 실제 격자 좌표로 정해지므로 다른 지점이나 달의 결과를 덮어쓰지 않습니다.
   - `tsmm_<tag>.md`: 사용 격자·단위, 전처리 설명, 비교표
   - `tsmm_<tag>.csv`: 비교표 (method, 평균 제거, 선형 추세 제거, 신뢰도 메모)
   - `series_<tag>.csv`: 일별 토양수분, 강수(mm/일), 전처리별 ACF(행 번호 = lag)

4. **사용자에게 보고.** 순서는 다음과 같습니다.
   1. 사용한 격자의 실제 위경도, 요청 지점과의 거리, 단위, 기간과 N, 시계열 범위·특징
   2. 입력 자료에 관한 주의 (예: 해상도와 변수 구성으로 본 실제 자료원)
   3. **전처리** 설명 (지켜야 할 것 5번)
   4. 비교표: 방법 | 평균 제거 | 선형 추세 제거 | 신뢰도와 이유 (10개 방법 모두)
   5. 해석: 방법 간 차이, 추세 제거의 영향, 이 값을 어디까지 쓸 수 있는지
   6. 저장한 결과 파일 경로

## 확인 체크리스트

- [ ] 원본 nc 파일을 쓰기 모드로 열지 않았다
- [ ] 결과가 저장소 최상위 `results/`에 있다 (스킬 폴더 안이 아님)
- [ ] 비교표에 10개 방법이 모두 있고, 빠진 값마다 이유가 있다
- [ ] 격자의 실제 위경도와 단위를 보고했다
- [ ] 전처리 설명이 표 위에 있다
- [ ] 보고한 숫자가 모두 스크립트 출력과 일치한다
